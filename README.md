# MONVÉ

Премиальный fashion e-commerce сайт (портфолио-проект).

**Слоган:** Меньше лишнего. Больше тебя.

## Стек

- React + TypeScript + Vite
- Tailwind CSS
- Motion (Framer Motion)
- React Router
- Zustand + localStorage
- Lucide React

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Страницы

- `/` — главная
- `/catalog` — каталог с фильтрами и сортировкой
- `/product/:slug` — карточка товара
- `/cart` — корзина
- `/favorites` — избранное
- `/checkout` — оформление (демо)
- `/order-confirmation` — подтверждение заказа
- `/about` — о бренде
- `/delivery`, `/returns`, `/faq`, `/contacts`, `/privacy`, `/terms`

Весь пользовательский интерфейс на русском языке. Оплата и отправка заказов — демонстрационные.
